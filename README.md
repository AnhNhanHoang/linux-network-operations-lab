# Linux Network Operations Lab

## Project goal

This repository documents my hands-on journey in building practical Linux,
networking, Bash automation, and troubleshooting skills for entry-level
infrastructure and cloud operations roles in Australia.

## Starting point

I am rebuilding my IT fundamentals from the ground up.

At the beginning of this project:

- Linux administration: beginner
- Networking: beginner
- Cloud administration: beginner
- Professional IT experience: none
- Programming: basic foundation

This repository documents learning and lab experience. It does not claim
production experience.

## Sprint scope

During this foundation sprint, I will practise:

- Linux filesystem, users, permissions and packages
- Processes, services, systemd and logs
- SSH, Nginx and host firewall configuration
- IPv4, CIDR, routing, DNS, TCP/UDP and HTTP
- Bash health-check automation
- Eight controlled break-fix incidents
- Technical documentation and troubleshooting explanations

## Working method

Learn → Lab → Build → Break → Troubleshoot → Fix → Document → Explain

## Planned evidence

This repository will contain:

- Architecture diagrams
- Deployment and recovery runbooks
- Bash scripts
- Command outputs and test results
- Eight incident reports
- Lessons learned
- A final practical assessment

## Repository structure

- `docs/` — General documentation about the lab and its design.
- `runbooks/` — Repeatable operational and recovery procedures.
- `incidents/` — Troubleshooting records, evidence, and root-cause analysis.
- `scripts/` — Automation scripts and operational checks.
- `diagrams/` — Network and system architecture diagrams.
- `evidence/` — Selected evidence produced during labs.
- `learning-log/` — Daily and weekly learning notes.
- `logs/` — Sanitised command or application output.
