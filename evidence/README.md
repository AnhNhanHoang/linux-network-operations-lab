# Evidence

## Naming convention

Format: `day-XX-short-description.ext`

Examples:

- `day-03-repo-tree.png`
- `day-03-git-status-clean.png`
- `day-19-nginx-health-check.txt`

## Rules

- Use lowercase words separated by hyphens.
- Evidence must support a Definition of Done.
- Do not store passwords, tokens, private keys, VM disks, or company data.
- Prefer command output, test results, commit links, and selective screenshots.
